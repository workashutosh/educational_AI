# About ClassKit

ClassKit helps schools turn class notes into something students and teachers can actually use — ask questions, make presentations, run practice tests, and hold lectures with notes and AI help in one place.

Think of it as: **Making Learning Easy.**

---

## Who it’s for

| Role | What they do |
|------|----------------|
| **School admin / manager** | Set up the school, create subject areas (AI Buckets), control who can access what, and use all teaching tools |
| **Teacher** | Upload notes, chat with the notes, create presentations and tests, run lectures — for the subjects they’ve been given access to |
| **Student** | Ask questions about their notes, join lectures, take assigned tests, and see results when teachers release them |

People join either by creating a school, using a school join code, or with a login a teacher creates for them.

---

## What we’ve built (available now)

### Getting started
- Create a school and finish a short onboarding (school details, email verification, plan limits)
- Join an existing school with a join code (as teacher or student)
- Sign in for all roles from one login page

### AI Buckets (subject folders)
- Organise teaching material by subject / class
- Upload **class notes** and **previous question papers**
- Supported files include PDFs, Word docs, PowerPoint, and images (including scans)
- Track when a file is ready to use
- Admins/managers can grant or remove access for teachers and students
- See how “built up” a bucket is (notes, tests, students using it)

### AI Chat
- Ask questions based on the notes in a bucket (not random internet answers)
- See which parts of the notes the answer came from
- Suggested follow-up questions after each answer (“You might want to ask about…”)
- Save conversations and come back to them later
- Students only see buckets they’ve been given access to

### Create presentations
- Teachers can generate a slide deck from a bucket’s notes
- Choose how many slides, preview on screen, then download a PowerPoint file

### Mock tests
- Teachers build a test plan (question types, marks, time limit)
- The system can generate questions from notes and/or past papers
- Edit questions before publishing
- Assign tests to students and open/close them
- Students take timed tests; answers for objective questions are scored automatically
- Short written answers can get a suggested score; teachers can confirm or change marks
- Teachers choose whether scores show immediately or after review
- Optional **class leaderboard** (teacher turns it on; students see polite ranks)

### Lectures
- Schedule a lecture linked to an AI Bucket
- Open a **lecture room** with class notes and in-room AI help
- Mark a class as live or ended
- Students see lectures for subjects they can access
- Teachers can connect a Microsoft account so the app creates a **Teams meeting link** for them (or they can paste a link if needed)

### Learning habits & engagement
- **Streaks** for students (days in a row asking or taking quick checks), shown on Home
- **Quick checks** — three short questions after new notes are ready or a lecture ends
- **Subject progress** bars built from tests, quick checks, and chat
- **Time saved** estimate for teachers (from AI-generated tests and presentations)
- **In-app notifications** (bell) plus optional email digests (daily for teachers, weekly for students)
- Home nudges such as “students haven’t started a test” or “new notes in Physics”

### Students & school settings
- Teachers/admins can create student logins and optionally give bucket access
- View a searchable list of students
- See school plan limits (how many buckets, storage, seats) and the join code
- Notification preferences (email digests, leaderboard visibility for students)
- Sign out and manage basic account info

### Home dashboard
- Students: streak, progress, open quick checks, tests, and chat shortcuts
- Staff: time saved, follow-up nudges, bucket investment summaries, and teaching shortcuts

## What’s still coming / not finished yet

These are planned or only partly ready — not fully available as a polished product experience yet:

| Area | What’s going on |
|------|------------------|
| **Paid plans & billing** | Plan options show “paid / more” as coming soon. There is no payment or upgrade checkout in the app yet. |
| **Teams meeting links for every school** | Creating meeting links from the app works when Microsoft is connected properly. Some schools still need that one-time Microsoft setup; until then, teachers can paste a Teams link by hand. |
| **Automatic question-paper generator (separate tool)** | Mock tests already generate practice questions from notes. A dedicated “exam paper generator” as its own product feature is not part of the current release. |
| **Larger school / multi-campus hosting** | The current product is aimed at a small number of schools running together. Bigger cloud storage / multi-region setups are future work. |
| **Richer classroom tools** | Attendance, gradebooks, parent portals, and full timetable systems are not in the product yet. |
| **Push notifications on phones** | Nudges today are in-app and email; mobile push is not included yet. |

---

## In short

**Ready to use today:** school setup, AI Buckets with notes and papers, AI chat with suggestions, PowerPoint generation, full mock-test cycle with optional leaderboards, lectures with notes + AI, student habit loops (streaks, quick checks, progress), teacher time-saved and class nudges, and Teams links when Microsoft is connected.

**Still ahead:** paid upgrades/billing, smoother Teams setup for every tenant, and broader school features beyond notes, tests, and live class rooms.
